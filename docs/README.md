## Tools

- **List Files**: `list_dir '.'`
- **Read File**: `read_file <path>`
- **Write File**: `write_file <path> <content>`
- **Create Directory**: `mkdir <path>`
- **Change Directory**: `cd <path>`
- **Run Command**: `run_command <command>`
- **Web Search**: `web_search <query>`
- **Fetch URL**: `fetch_url <url>`
